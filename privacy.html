Privacy / Confidentialité

Updated: 27 September 2026 · Contact: sbissi.mohamed@esprit.tn

English

This portfolio belongs to Mohamed Sbissi, Tunis, Tunisia. Contact cards and sharing work without optional statistics. The site never reads your contacts or saves a contact without your device’s confirmation.

Language preferences are stored locally. If optional statistics are configured, you may freely allow or refuse them, with the same access to the site. No analytics events are sent before you allow them. “Privacy choices” in the footer lets you withdraw permission or delete the current visit’s data.

Statistics contain a random visit code, server timestamps, selected button events and estimated active viewing time. A code identifies a browser visit, not a named person. The application does not collect names, emails, contact lists, fingerprints, IP addresses, full browsing URLs or referrers for analytics. Viewing time pauses when the tab is hidden or after 60 seconds without interaction; it is approximate and does not prove attention. Clicks do not prove that a contact was saved, a message was sent or a CV was read.

If activated, the collector uses Cloudflare Workers and D1, independently of GitHub Pages. Statistics are accessible only through an authenticated private dashboard. Events are removed after 30 days; inactive visit records expire 30 days after their last activity. Providers may process technical network data to deliver and secure their services under their own terms. The application’s analytics database excludes those network details.

Do Not Track and Global Privacy Control signals disable optional statistics. Blocking scripts or refusing statistics does not block the portfolio. You can ask for access or deletion using your random visit code, available in this browser’s statistics session storage, or use “Delete this visit’s data”. Contact the owner for privacy questions. Where applicable, you can complain to your competent data protection authority. Publishing and enabling the backend requires the owner to check hosting terms, data location and any applicable transfer requirements.

After deletion, only the random visit code is kept in a suppression list for up to 30 days to prevent delayed requests recreating the deleted record.

Français

Ce portfolio appartient à Mohamed Sbissi, Tunis, Tunisie. L’enregistrement de la fiche contact et le partage fonctionnent sans statistiques facultatives. Le site ne lit pas votre carnet d’adresses et n’enregistre pas de contact sans confirmation sur votre appareil.

La préférence de langue est conservée localement. Si les statistiques sont configurées, vous pouvez les accepter ou les refuser librement, avec le même accès au site. Aucun événement analytique n’est envoyé avant votre accord. « Choix de confidentialité » dans le pied de page permet de retirer cet accord ou de supprimer les données de la visite actuelle.

Les statistiques comprennent un code de visite aléatoire, des horodatages serveur, certains clics et une estimation du temps de consultation actif. Ce code représente une visite dans un navigateur, et non une personne identifiée. L’application ne collecte pas de noms, d’adresses e-mail, de contacts, d’empreintes numériques, d’adresses IP, d’URL complètes ni de sites référents pour les statistiques. Le temps est suspendu lorsque l’onglet est masqué ou après 60 secondes sans interaction. Il ne prouve pas l’attention ; un clic ne prouve ni l’enregistrement d’un contact, ni l’envoi d’un message, ni la lecture du CV.

Lorsqu’il est activé, le collecteur utilise Cloudflare Workers et D1, séparément de GitHub Pages. Le tableau de bord privé exige une authentification. Les événements expirent après 30 jours ; les visites inactives sont supprimées 30 jours après leur dernière activité. Les hébergeurs peuvent traiter des données réseau techniques pour fournir et sécuriser leurs services, selon leurs propres conditions. Ces informations sont exclues de la base analytique de l’application.

Les signaux Do Not Track et Global Privacy Control désactivent les statistiques facultatives. Vous pouvez utiliser « Supprimer les données de cette visite » ou contacter le propriétaire avec votre code de visite. Selon votre situation, vous pouvez saisir l’autorité de protection des données compétente. Avant d’activer le service, le propriétaire doit vérifier les conditions d’hébergement, la localisation des données et les règles de transfert applicables.

Après suppression, seul le code de visite aléatoire est conservé dans une liste de blocage pendant 30 jours au maximum pour empêcher des requêtes retardées de recréer les données supprimées.
